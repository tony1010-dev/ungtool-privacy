개인정보처리방침

시행일: 2026년 10월 16일 (이전: 2026년 10월 15일)

웅툴은 사용자의 정보를 외부로 보내지 않습니다. 모든 기능은 사용자의 브라우저 안에서만 동작합니다.

웅툴(이하 “확장 프로그램”)은 사용자의 개인정보를 소중히 여기며, 다음과 같이 정보를 처리합니다.

1. 수집·전송하는 정보

확장 프로그램은 사용자의 개인정보를 수집하지 않으며, 개발자 서버나 제3자에게 전송하지 않습니다. 개발자 서버나 제3자 서버와 통신하는 기능이 없으며, 네트워크 요청은 아래 4항의 사내 CMS 조회에만 사용합니다.

2. 브라우저에만 저장되는 정보

기능 제공을 위해 아래 정보가 사용자의 브라우저(chrome.storage.local, IndexedDB)에만 저장됩니다.

  • OTP 계정 정보: 사용자가 QR 이미지로 직접 등록한 발급처, 계정 이름, 비밀 키
  • 설정: 화면 테마, 기능 켜기/끄기, CMS 즐겨찾기 메뉴, CMS 표에서 숨긴 열 목록, 입고지시 화면의 열 설정
  • PDF 작업 파일: 편집한 PDF를 새 탭으로 열거나 독립 창으로 옮길 때만 잠시 보관하며, 연 뒤 바로 지웁니다.

3. 파일 처리

PDF·ZIP·QR 이미지 파일은 사용자의 컴퓨터 안에서만 처리되며 외부로 업로드되지 않습니다. CMS 분석 결과와 면장 Excel 파일도 브라우저 안에서 만들어 사용자의 컴퓨터에 바로 저장합니다.

4. 웹사이트 접근

확장 프로그램은 https://cms.siliconii.com 화면에서만 메뉴 빠른이동, 표 열 숨기기, 다중 번호 검색, 입/출고 분석, 면장 다운로드, 입고지시 보조 메뉴를 표시합니다.

  • 다중 번호 검색과 면장 다운로드는 사용자가 버튼을 누를 때, 이미 로그인된 CMS에 같은 사이트 안에서 조회 요청을 보냅니다. 받은 내용은 화면 표시와 Excel 파일 생성에만 쓰며 다른 곳으로 보내지 않습니다.
  • 입/출고 분석은 CMS 화면에 이미 불러온 목록 데이터를 읽어 브라우저 안에서 계산합니다.
  • 모든 기능은 조회와 화면 표시만 하며 회사 시스템의 데이터를 바꾸지 않습니다.

5. 정보 삭제

  • OTP 계정: 웅툴 › 설정 › OTP 인증코드에서 계정별로 삭제할 수 있습니다.
  • 확장 프로그램을 삭제하면 브라우저에 저장된 모든 정보가 함께 삭제됩니다.

6. 문의

개인정보 관련 문의: tony@siliconii.net

7. 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 알립니다.

Privacy Policy

Effective date: October 16, 2026 (previous: October 15, 2026)

Ungtool does not send your information anywhere. Every feature runs entirely inside your browser.

Ungtool (“the extension”) respects your privacy. This policy explains how information is handled.

1. Information collected or transmitted

The extension does not collect personal information and does not transmit any data to the developer or to third parties. It has no functionality that communicates with the developer’s or any third-party server; its only network requests are the company CMS lookups described in section 4.

2. Information stored only in your browser

To provide its features, the extension stores the following data only in your browser (chrome.storage.local and IndexedDB):

  • OTP accounts: the issuer, account name and secret key that you register yourself from a QR image
  • Settings: theme, feature on/off switches, CMS favorite menus, the list of hidden CMS table columns and column settings on the inbound allocation page
  • PDF working files: kept briefly only when an edited PDF is opened in a new tab or moved to a separate window, and deleted right after it is opened

3. File processing

PDF, ZIP and QR image files are processed only on your computer and are never uploaded. CMS analysis results and customs Excel files are also generated inside the browser and saved directly to your computer.

4. Website access

The extension shows its quick menu search, column hiding, multi-number search, inbound/outbound analysis, customs download and inbound allocation helper only on https://cms.siliconii.com.

  • Multi-number search and customs download send lookup requests to the CMS you are already signed in to, within the same site, only when you press their buttons. The responses are used only to display results and build Excel files, and are not sent anywhere else.
  • Inbound/outbound analysis reads the list data already loaded on the CMS page and calculates inside the browser.
  • All features only read and display data; they never modify the company system’s data.

5. Deleting your data

  • OTP accounts can be deleted individually in Ungtool › Settings › OTP.
  • Removing the extension deletes all data it stored in your browser.

6. Contact

Privacy questions: tony@siliconii.net

7. Changes

If this policy changes, the updated policy and its effective date will be posted on this page.
